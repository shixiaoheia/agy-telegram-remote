# 安装与管理菜单

下载并运行 `install.sh` 后，首次安装和已有安装都会显示菜单：

1. 安装：首次安装或沿用现有配置执行部署。
2. 更新：使用同一部署流程，保留原配置、模型、权限和路径设置。
3. 彻底卸载：查看清理和保留范围，输入 y 确认或 n 取消。
0. 退出：不开始安装或卸载。

首次安装推荐选 1；检测到已有安装时推荐选 2。输入 Token 前可选择隐藏或显示，直接回车默认隐藏；Token 与数字 ID 的格式不正确可当场重输，格式校验不代替 Telegram 联网验证。

安装与更新会检查新版本、配置及服务就绪；停止现有服务前会检查子进程并询问是否继续。检查是即时快照，不能排除任务在检查之后开始；已有任务不会自动重跑。配额、网络等非授权自检失败不会自动触发重新授权。需要修改 Token 或白名单时使用 `--reconfigure`。

失败时按已知分类提示下一步，并显示是否已尝试回退及 systemd 查询到的服务状态；查不到状态时会明确说明并给出检查命令。

彻底卸载清除服务、程序、配置、任务记录、备份、运行文件和默认及当前工作目录中的 Bot 临时附件；确认前展示路径，无法安全识别或有符号链接时中止。历史工作目录不自动搜索。有安装标记时还清除由本安装器安装的 agy 和对应 Google 登录资料。独立安装或来源不明的 agy 和资料、工作目录、用户文件、系统日志、自定义 systemd 配置、部署锁文件和 BotFather 中的 Bot 保留。下载的 `install.sh` 需自行删除。取消或输入结束不会停止服务。

`--install`、`--root`、`--reconfigure`、`--ref` 等显式参数可直接进入安装或更新流程；`--uninstall` 只移除服务，`--uninstall --purge` 清理以上项目数据，两者都需要 y/n 确认。`--help` 查看全部参数。

离线回归使用临时目录和模拟服务，不在宿主机执行实际安装或卸载。运行 `bash scripts/verify.sh` 复验。
