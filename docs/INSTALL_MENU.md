# 安装与管理菜单

下载并运行 `install.sh` 后，首次安装和已有安装都会显示菜单：

1. 安装：首次安装或沿用现有配置执行部署。
2. 更新：使用同一部署流程，保留原配置、模型、权限和路径设置。
3. 彻底卸载：查看清理和保留范围，输入 y 确认或 n 取消。
0. 退出：不开始安装或卸载。

安装与更新会检查新版本、配置及服务就绪；已有任务不会自动重跑。需要修改 Token 或白名单时使用 `--reconfigure`。

彻底卸载清除服务、程序、配置、任务记录、备份、运行文件和默认工作目录中的 Bot 临时附件；有安装标记时还清除由本安装器安装的 agy 和对应 Google 登录资料。自定义工作目录中的附件缓存可能保留，请自行检查。独立安装或来源不明的 agy 和资料、工作目录、用户文件、系统日志、自定义 systemd 配置、部署锁文件和 BotFather 中的 Bot 保留。下载的 `install.sh` 需自行删除。取消或输入结束不会停止服务。

`--install`、`--root`、`--reconfigure`、`--ref` 等显式参数可直接进入安装或更新流程；`--uninstall` 只移除服务，`--uninstall --purge` 清理以上项目数据，两者都需要 y/n 确认。`--help` 查看全部参数。

离线回归使用临时目录和模拟服务，不在宿主机执行实际安装或卸载。运行 `bash scripts/verify.sh` 复验。
